# OCaml: Углубленные материалы

Коллекция технических материалов об OCaml - функциональном языке программирования с мощной системой типов и модульной архитектурой.

## Содержание

### Технические тезисы

**Файл:** [ocaml_technical_theses.md](ocaml_technical_theses.md)

Систематизированный обзор технических особенностей и концепций OCaml:

- Система типов и type inference
- Модульная система (модули, функторы, сигнатуры)
- Pattern matching и алгебраические типы данных
- Функциональные возможности и императивные конструкции
- Memory management и производительность
- Инструментарий и экосистема

### Сравнение OCaml и F#

**Файл:** [ocaml-fsharp-detailed-comparison.md](ocaml-fsharp-detailed-comparison.md)

Детальное сравнение двух родственных ML-языков:

- Синтаксические различия
- Системы типов и inference
- Модульные системы
- Экосистемы и tooling
- Области применения
- Философия и дизайн-решения

### Экосистема OCaml для JavaScript

**Файл:** [ocaml-js-ecosystem-reasonml-rescript-melange.md](ocaml-js-ecosystem-reasonml-rescript-melange.md)

Обзор инструментов компиляции OCaml в JavaScript:

- **ReasonML** - альтернативный синтаксис для OCaml
- **ReScript** - язык с JS-интеропом (бывший BuckleScript)
- **Melange** - компилятор OCaml в JavaScript
- Сравнение подходов и use cases

### Алгебраические эффекты в OCaml 5

**Файл:** [ocaml5-algebraic-effects.md](ocaml5-algebraic-effects.md)

Революционная возможность OCaml 5:

- Концепция алгебраических эффектов
- Effect handlers
- Практические применения (concurrency, generators, async/await)
- Сравнение с монадами и другими подходами
- Примеры кода

### Форк Jane Street

**Файл:** [oxcaml-jane-street-fork.md](oxcaml-jane-street-fork.md)

Обзор модификаций OCaml от Jane Street Capital:

- Мотивация создания форка
- Расширения языка
- Специфичные библиотеки и инструменты
- Отличия от стандартного OCaml
- Процесс интеграции изменений обратно в основную ветку

## Связь с докладами

Эти материалы используются в качестве справочной информации для доклада [Railway-Oriented Programming](../ROP/README.md), где OCaml используется для примеров функционального подхода к обработке ошибок.

## Целевая аудитория

Материалы рассчитаны на:

- Разработчиков, знакомых с функциональным программированием
- Тех, кто изучает OCaml или рассматривает его для проекта
- Интересующихся современными возможностями ФП-языков
- Сравнивающих различные ML-подобные языки
