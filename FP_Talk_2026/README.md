# Доклад: "Rust, Scala и JavaScript сидят в баре"

Материалы для конференционного доклада о фундаментальных свойствах функционального программирования.

## Содержание папки

- **CFP.md** — тезисы для подачи на конференцию (Call For Papers)
- **fp_languages_review.md** — полный опорный документ с примерами на 11 языках
- (будет добавлено) слайды презентации
- (будет добавлено) примеры кода для демонстрации

## Концепция доклада

Демонстрация пяти фундаментальных свойств функционального программирования через сравнение пяти языков с разной философией:

1. **OCaml** — академическая чистота
2. **Scala** — JVM-прагматизм
3. **Python** — простота
4. **JavaScript** — вездесущность
5. **Rust** — системная безопасность

## Целевая аудитория

Middle/Senior разработчики, знакомые хотя бы с одним из рассмотренных языков.

## Формат

40-45 минут, intermediate level, с живыми примерами кода.
