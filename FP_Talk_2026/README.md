## Концепция доклада

Пять фундаментальных свойств ФП через сравнение пяти языков с разной философией. Сквозной принцип — декларативность: код описывает задачу, а не управляет потоком выполнения.

1. **OCaml** — академическая чистота
2. **Scala** — JVM-прагматизм
3. **Python** — простота
4. **JavaScript** — вездесущесть
5. **Rust** — системная безопасность

## Бонус-трек

Production-пример на Ruby: DDD-фреймворк на dry-rb (телеком-домен, NDA). Демонстрирует все пять принципов в реальном коде: ROP-конвейер, do-нотация, типовые контракты, доменные ошибки как значения, бизнес-DSL с pattern matching.

## Целевая аудитория

Middle/Senior разработчики, знакомые хотя бы с одним из рассмотренных языков.

## Формат

40-45 минут, intermediate level, с живыми примерами кода.
