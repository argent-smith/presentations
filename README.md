# Технические презентации и доклады

Репозиторий содержит материалы для технических докладов по функциональному программированию, архитектуре ПО и современным технологиям.

## Структура

Каждый доклад организован в отдельную папку.

## Доклады

### Railway-Oriented Programming: Функциональный подход к обработке ошибок

**Папка:** `ROP/`

Доклад о Railway-Oriented Programming - элегантном функциональном подходе к обработке ошибок.

Подробности см. в [README доклада](ROP/README.md).

### Капля ФП в мире лошадей и хомячков

**Папка:** `FP_REVIEW/`

Доклад о практическом применении элементов функционального программирования для борьбы со сложностью в реальных проектах.

Подробности см. в [README доклада](FP_REVIEW/README.md).

### Древняя магия в повседневном коде

**Папка:** `FP_Talk_2026/`

Конференционный доклад о пяти фундаментальных свойствах ФП через сравнение OCaml, Scala, Rust, Python и JavaScript.
Презентация для Стачки 2026 — в [`FP_Talk_2026/nastachku/`](FP_Talk_2026/nastachku/).

Подробности см. в [README доклада](FP_Talk_2026/README.md).

## Углубленные материалы

### OCaml

**Папка:** `OCaml/`

Коллекция технических материалов об OCaml: технические тезисы, сравнение с F#, экосистема для JavaScript, алгебраические эффекты, форк Jane Street.
