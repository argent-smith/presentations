# Как использовать этот Obsidian vault

← [[README|Главная]]

## Структура vault

Этот Obsidian vault организован как **Map of Content (MOC)** для изучения функционального программирования в 11 языках.

### Основные разделы

```
FP_OBSIDIAN/
├── README.md                          # Главная навигационная страница (MOC)
├── _Как использовать.md               # Эта инструкция
├── 00-Введение/                       # Базовые концепции ФП
├── 01-Фундаментальные-свойства/       # 5 основных свойств ФП
├── 02-Вспомогательные-свойства/       # 7 дополнительных свойств
├── 03-Языки/                          # Описания 11 языков
├── 04-Сравнения/                      # Сравнительные таблицы
└── 05-Ресурсы/                        # Материалы для изучения
```

## Стратегии изучения

### 1. Путь новичка (от концепций к языкам)

1. Начните с [[README|главной страницы]]
2. Прочитайте [[00-Введение/Что такое ФП|введение в ФП]]
3. Изучите [[01-Фундаментальные-свойства/_О фундаментальных свойствах|5 фундаментальных свойств]]
4. Выберите язык из [[00-Введение/Обзор 11 языков|обзора языков]]
5. Практикуйтесь, возвращаясь к концепциям

### 2. Путь практика (от языка к концепциям)

1. Перейдите в [[03-Языки/|раздел языков]]
2. Выберите ваш текущий язык (например, [[03-Языки/Python|Python]])
3. Изучите, какие ФП-возможности доступны
4. Переходите по ссылкам к соответствующим свойствам
5. Сравните с другими языками через таблицы

### 3. Путь исследователя (сравнение языков)

1. Откройте [[04-Сравнения/Фундаментальные свойства|сводные таблицы]]
2. Сравните языки по интересующим свойствам
3. Переходите к детальным описаниям языков
4. Изучайте примеры кода в [[../fp_languages_review.md|полном обзоре]]

## Навигация в Obsidian

### Внутренние ссылки

Все заметки связаны через `[[ссылки]]`:
- Нажмите на ссылку — перейдете к заметке
- Hover над ссылкой — увидите preview
- Ctrl/Cmd + клик — откроет в новой панели

### Граф связей (Graph View)

1. Откройте Graph View (Ctrl/Cmd + G)
2. Визуально увидите связи между концепциями
3. Кластеры показывают тематические группы:
   - Фундаментальные свойства (центр)
   - Языки (периферия)
   - Вспомогательные свойства (связи)

### Поиск по тегам

Используйте теги для фильтрации:
- `#фундаментальное` — базовые свойства ФП
- `#вспомогательное` — дополнительные свойства
- `#язык` — описания языков программирования
- `#сравнение` — сравнительные таблицы
- `#ресурсы` — материалы для изучения

Откройте панель Tags (правый sidebar) для быстрого доступа.

### Backlinks

Каждая заметка показывает:
- **Linked mentions** — где на нее ссылаются явно
- **Unlinked mentions** — где она упоминается текстом

Это помогает найти связанные концепции.

## Работа с исходным материалом

Этот vault — **навигационная структура** поверх [[../fp_languages_review.md|полного обзора]].

- **Краткие заметки** — для быстрой навигации и понимания концепций
- **Полный обзор** — для детальных примеров кода на всех языках

Рекомендуемый workflow:
1. Используйте vault для навигации и изучения концепций
2. Обращайтесь к полному обзору для примеров кода
3. Практикуйтесь в своей IDE с выбранным языком

## Расширение vault

Вы можете дополнять vault своими заметками:

### Личные заметки

Создайте папку `_Личное/` для:
- Конспектов при изучении
- Примеров вашего кода
- Заметок о прочитанных статьях

### Связывание с внешними ресурсами

Добавляйте ссылки на:
- Статьи и блог-посты
- Видео-курсы
- Ваши проекты на GitHub

### Дневник изучения

Ведите дневник прогресса:
```markdown
## 2025-10-15
- Изучил [[01-Фундаментальные-свойства/Чистые функции]]
- Попрактиковался в [[03-Языки/Python]]
- Вопрос: как изолировать IO в Python?
```

## Горячие клавиши Obsidian

- `Ctrl/Cmd + N` — новая заметка
- `Ctrl/Cmd + O` — быстрый переход (Quick Switcher)
- `Ctrl/Cmd + G` — граф связей
- `Ctrl/Cmd + Click` — открыть в новой панели
- `Alt + ←/→` — навигация назад/вперед

## Полезные плагины Obsidian

Рекомендуемые community plugins:
- **Dataview** — запросы по заметкам
- **Tag Wrangler** — управление тегами
- **Quick Switcher++** — улучшенная навигация
- **Mind Map** — визуализация связей

## Режимы просмотра

### Reading Mode
Чистый вид для чтения без markdown-синтаксиса

### Editing Mode
Редактирование с предпросмотром ссылок

### Source Mode
Сырой markdown для копирования кода

Переключение: Ctrl/Cmd + E
