# Функции первого класса

← [[README|Главная]] | [[00-Введение/Что такое ФП|Введение]]

## Определение

Функции являются полноценными значениями — их можно присваивать переменным, передавать как аргументы, возвращать как результаты.

## Что такое значение (value)

**Значение** — неизменяемый результат вычисления, который можно использовать в программе. Примеры: числа (42), строки ("hello"), булевы значения (true/false), функции, структуры данных.

В функциональном программировании **функции — такие же значения, как числа или строки**.

## Зачем это нужно

- **Абстракция** — создание обобщенных решений
- **Композиция** — построение сложного из простого
- **Переиспользование кода** — функции как строительные блоки
- **Высшего порядка функции** — функции, принимающие или возвращающие функции

## Примеры на всех языках

### [[03-Языки/OCaml|OCaml]]

```ocaml
(* OCaml *)
let create_multiplier factor = fun x -> x * factor
let triple = create_multiplier 3
```

### [[03-Языки/F-Sharp|F#]]

```fsharp
// F# (родственник OCaml на .NET)
let createMultiplier factor = fun x -> x * factor
let triple = createMultiplier 3
```

### [[03-Языки/Clojure|Clojure]]

```clojure
;; Clojure
(defn create-multiplier [factor]
  (fn [x] (* x factor)))
(def triple (create-multiplier 3))
```

### [[03-Языки/Scala|Scala]]

```scala
// Scala 3
def createMultiplier(factor: Int): Int => Int =
  x => x * factor
val triple = createMultiplier(3)
```

### [[03-Языки/Ruby|Ruby]]

```ruby
# Ruby
create_multiplier = ->(factor) { ->(x) { x * factor } }
triple = create_multiplier.call(3)
```

### [[03-Языки/Rust|Rust]]

```rust
// Rust
fn create_multiplier(factor: i32) -> impl Fn(i32) -> i32 {
    move |x| x * factor
}
let triple = create_multiplier(3);
```

### [[03-Языки/Go|Go]]

```go
// Go
func createMultiplier(factor int) func(int) int {
    return func(x int) int { return x * factor }
}
triple := createMultiplier(3)
```

### [[03-Языки/JavaScript|JavaScript]]

```javascript
// JavaScript
const createMultiplier = factor => x => x * factor;
const triple = createMultiplier(3);
```

### [[03-Языки/TypeScript|TypeScript]]

```typescript
// TypeScript
const createMultiplier = (factor: number): (x: number) => number =>
    x => x * factor;
const triple = createMultiplier(3);
```

### [[03-Языки/Python|Python]]

```python
# Python
def create_multiplier(factor):
    return lambda x: x * factor
triple = create_multiplier(3)
```

### [[03-Языки/Java|Java]]

```java
// Java
Function<Integer, Integer> createMultiplier(int factor) {
    return x -> x * factor;
}
Function<Integer, Integer> triple = createMultiplier(3);
```

### [[03-Языки/C++|C++]]

```cpp
// C++
auto create_multiplier(int factor) {
    return [factor](int x) { return x * factor; };
}
auto triple = create_multiplier(3);
```
