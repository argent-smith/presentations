# О фундаментальных свойствах

← [[README|Главная]]

Пять фундаментальных свойств составляют основу функционального программирования. Эти свойства определяют саму суть парадигмы.

## Пять фундаментальных свойств

1. **[[01-Фундаментальные-свойства/Функции первого класса|Функции первого класса]]**
   - Функции как полноценные значения
   - Передача функций как аргументов
   - Возврат функций как результатов
   - Основа для абстракции и композиции

2. **[[01-Фундаментальные-свойства/Чистые функции|Чистые функции и ссылочная прозрачность]]**
   - Детерминизм: одинаковый вход → одинаковый выход
   - Отсутствие побочных эффектов
   - Предсказуемость и тестируемость
   - Возможность оптимизации

3. **[[01-Фундаментальные-свойства/Иммутабельность|Иммутабельность данных]]**
   - Данные не изменяются после создания
   - Вместо модификации — создание новых структур
   - Безопасность в многопоточной среде
   - Устранение race conditions

4. **[[01-Фундаментальные-свойства/Декларативный стиль|Декларативный стиль]]**
   - Описание "что требуется", а не "как делается"
   - Фокус на результате, а не на процессе
   - Более высокий уровень абстракции
   - Читаемость и поддерживаемость

5. **[[01-Фундаментальные-свойства/Выражения|Выражения вместо инструкций]]**
   - Всё вычисляется в значение
   - Нет разделения на statements и expressions
   - Композируемость на уровне языка
   - Естественная ссылочная прозрачность

## Взаимосвязи

Эти свойства тесно связаны и усиливают друг друга:

- **Чистые функции** легче реализовать с **иммутабельными данными**
- **Функции первого класса** позволяют строить **декларативные** API
- **Выражения** способствуют **ссылочной прозрачности**
- **Иммутабельность** упрощает написание **чистых функций**

## Почему именно пять

Эти пять свойств являются **необходимым минимумом** для функционального стиля:

- Без **функций первого класса** невозможна композиция
- Без **чистоты** теряется предсказуемость
- Без **иммутабельности** сложно гарантировать чистоту
- Без **декларативности** код становится императивным
- Без **выражений** теряется композируемость
