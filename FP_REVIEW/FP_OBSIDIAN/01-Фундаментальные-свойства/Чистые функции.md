# Чистые функции и ссылочная прозрачность

← [[README|Главная]] | [[01-Фундаментальные-свойства/Функции первого класса|Предыдущее]]

## Определение

**Чистая функция** — детерминированная функция без побочных эффектов (одинаковый вход → одинаковый выход).

**Ссылочная прозрачность (referential transparency)** — выражение называется ссылочно прозрачным, если его можно заменить соответствующим значением без изменения поведения программы.

Чистая функция — это функция, результат вызова которой является ссылочно прозрачным для всех ссылочно прозрачных аргументов.

## Зачем это нужно

- **Предсказуемость** — одинаковые входы всегда дают одинаковые выходы
- **Тестируемость** — не нужны моки и стабы для внешних зависимостей
- **Параллелизуемость** — чистые функции безопасно выполнять параллельно
- **Оптимизируемость** — компилятор может применять мемоизацию и удаление общих подвыражений
- **Рефакторинг** — можно безопасно заменять вызовы на их результаты

Ссылочная прозрачность позволяет программисту и компилятору рассуждать о поведении программы как о системе перезаписи, что упрощает верификацию, рефакторинг и оптимизацию.

## Примеры чистых функций

### [[03-Языки/OCaml|OCaml]]

```ocaml
(* OCaml *)
let add a b = a + b
let multiply x y = x * y
let compose f g x = f (g x)
(* Все вызовы детерминированы и ссылочно прозрачны *)
```

### [[03-Языки/F-Sharp|F#]]

```fsharp
// F#
let add a b = a + b
let multiply x y = x * y
let compose f g x = f (g x)
// Чистые функции по умолчанию
```

### [[03-Языки/Clojure|Clojure]]

```clojure
;; Clojure
(defn add [a b] (+ a b))
(defn multiply [x y] (* x y))
(defn compose [f g] (fn [x] (f (g x))))
;; Иммутабельность и чистота поощряются языком
```

### [[03-Языки/Scala|Scala]]

```scala
// Scala 3
def add(a: Int, b: Int): Int = a + b
def multiply(x: Int, y: Int): Int = x * y
def compose[A, B, C](f: B => C, g: A => B): A => C =
  x => f(g(x))
// Чистые функции - идиоматичный стиль
```

### [[03-Языки/Ruby|Ruby]]

```ruby
# Ruby
add = ->(a, b) { a + b }
multiply = ->(x, y) { x * y }
compose = ->(f, g) { ->(x) { f.call(g.call(x)) } }
# Чистота достигается осознанно, язык не принуждает
```

### [[03-Языки/Rust|Rust]]

```rust
// Rust
fn add(a: i32, b: i32) -> i32 { a + b }
fn multiply(x: i32, y: i32) -> i32 { x * y }
fn compose<A, B, C, F, G>(f: F, g: G) -> impl Fn(A) -> C
where
    F: Fn(B) -> C,
    G: Fn(A) -> B,
{
    move |x| f(g(x))
}
// Чистота гарантируется системой владения
```

### [[03-Языки/Go|Go]]

```go
// Go
func add(a, b int) int {
    return a + b
}
func multiply(x, y int) int {
    return x * y
}
// Чистота достигается дисциплиной программиста
```

### [[03-Языки/JavaScript|JavaScript]]

```javascript
// JavaScript
const add = (a, b) => a + b;
const multiply = (x, y) => x * y;
const compose = (f, g) => x => f(g(x));
// Чистота - вопрос стиля, язык не принуждает
```

### [[03-Языки/TypeScript|TypeScript]]

```typescript
// TypeScript
const add = (a: number, b: number): number => a + b;
const multiply = (x: number, y: number): number => x * y;
const compose = <A, B, C>(f: (b: B) => C, g: (a: A) => B): (a: A) => C =>
  x => f(g(x));
// Типы помогают, но чистоту не гарантируют
```

### [[03-Языки/Python|Python]]

```python
# Python
def add(a, b):
    return a + b  # Всегда возвращает одно и то же для одних входных данных
                  # Выражение add(2, 3) можно заменить на 5 без изменения поведения

def calculate_discount(price, rate):
    return price * (1 - rate)  # Детерминированно, без эффектов
```

### [[03-Языки/Java|Java]]

```java
// Java
public static int add(int a, int b) {
    return a + b;
}

public static int multiply(int x, int y) {
    return x * y;
}

public static <A, B, C> Function<A, C> compose(
    Function<B, C> f,
    Function<A, B> g
) {
    return x -> f.apply(g.apply(x));
}
// Чистота - дисциплина программиста
```

### [[03-Языки/C++|C++]]

```cpp
// C++
auto add(int a, int b) -> int {
    return a + b;
}

auto multiply(int x, int y) -> int {
    return x * y;
}

template<typename F, typename G>
auto compose(F f, G g) {
    return [=](auto x) { return f(g(x)); };
}
// Чистота требует дисциплины, const помогает
```

## Примеры нечистых функций

### Изменяемое состояние

**[[03-Языки/OCaml|OCaml]]:**
```ocaml
(* Изменяемые ссылки *)
let counter = ref 0
let increment () =
  counter := !counter + 1;  (* Эффект! *)
  !counter
(* Результат зависит от внешнего состояния *)
```

**[[03-Языки/Python|Python]]:**
```python
# Глобальное состояние
counter = 0
def increment():
    global counter
    counter += 1  # Эффект!
    return counter  # НЕ ссылочно прозрачно
```

### Ввод-вывод

**[[03-Языки/Rust|Rust]]:**
```rust
// Ввод-вывод
fn greet_user() {
    println!("Введите имя:");  // Эффект!
    let mut name = String::new();
    std::io::stdin().read_line(&mut name).unwrap();  // Эффект!
    println!("Привет, {}!", name.trim());
}
```

### Случайность и недетерминизм

**[[03-Языки/JavaScript|JavaScript]]:**
```javascript
// Date.now()
function getCurrentTimestamp() {
    return Date.now();  // Недетерминированно!
}
```

**[[03-Языки/TypeScript|TypeScript]]:**
```typescript
// Случайность
function randomInt(max: number): number {
    return Math.floor(Math.random() * max);  // Недетерминированно!
}
```

## Практическая демонстрация ссылочной прозрачности

### Чистая функция

```ocaml
(* OCaml *)
let double x = x * 2
let result1 = double 5 + double 5  (* 10 + 10 = 20 *)
let result2 = 10 + 10              (* Можем заменить double 5 на 10 *)
(* result1 = result2 - замена не изменила поведение *)
```

```python
# Python - чистая функция
def square(x):
    return x * x

# Благодаря ссылочной прозрачности:
result1 = square(4) + square(4)  # 16 + 16 = 32
result2 = 16 + 16                # Можем заменить square(4) на 16
assert result1 == result2        # Поведение идентично
```

### Нечистая функция

```python
# Python - нечистая функция
import random
def random_int():
    return random.randint(1, 10)

# НЕ ссылочно прозрачно:
result3 = random_int() + random_int()  # Например, 3 + 7 = 10
result4 = 3 + 3                        # НЕЛЬЗЯ заменить вызовы на значения!
# result3 ≠ result4 - замена изменила поведение
```
