## Сильные стороны

1. **Persistent data structures** — эффективные иммутабельные структуры
2. **STM** — Software Transactional Memory для конкурентности
3. **Макросы** — метапрограммирование на уровне синтаксиса
4. **REPL-driven development** — интерактивная разработка
5. **Простота** — минималистичный синтаксис Lisp

## Типичные применения

- JVM-проекты с акцентом на иммутабельность
- Data-oriented приложения
- Конкурентное программирование с STM
- Веб-приложения (Ring, Compojure)

## Экосистема

- **Менеджер зависимостей:** Leiningen, deps.edn
- **Библиотеки:** core.async, Manifold, cats
- **ClojureScript:** компиляция в JavaScript
