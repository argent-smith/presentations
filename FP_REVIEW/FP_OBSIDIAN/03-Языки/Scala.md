## Краткая характеристика

**Scala** — мощный язык на JVM, балансирующий между ФП и ООП с продвинутой типовой системой.

## Сильные стороны

1. **Унификация ФП и ООП** — объекты и функции в гармонии
2. **Мощная типовая система** — generics, variance, higher-kinded types
3. **Implicits** — контекстно-зависимое разрешение
4. **For-comprehensions** — синтаксический сахар для монад
5. **Экосистема** — Akka, Spark, ZIO, Cats

## Типичные применения

- Корпоративные проекты на JVM
- Big data (Spark, Flink)
- Микросервисы с Akka
- Постепенная миграция с Java

## Экосистема

- **Компилятор:** scalac (Scala 2), dotty (Scala 3)
- **Build tools:** sbt, Mill
- **Библиотеки:** Cats, Cats Effect, ZIO, Akka
