**JavaScript** — вездесущий язык веба с функциями первого класса и гибкой динамической типизацией.

## Сильные стороны

1. **Функции первого класса** — natural ФП в языке
2. **Замыкания** — мощные и естественные
3. **Асинхронность** — Promises, async/await
4. **Экосистема** — огромная, npm
5. **Везде** — браузер, сервер (Node.js), мобильные, desktop

## Типичные применения

- Frontend-разработка (обязателен для браузера)
- Full-stack (Node.js)
- Мобильные приложения (React Native)
- Desktop (Electron)

## Экосистема

- **Runtime:** V8 (Chrome, Node.js), SpiderMonkey (Firefox)
- **Менеджер пакетов:** npm, yarn, pnpm
- **Библиотеки:** Ramda, Sanctuary, lodash/fp
