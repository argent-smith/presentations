← [[README|Главная]] | [[00-Введение/Обзор 11 языков|Обзор языков]]

## Краткая характеристика

**OCaml** — эталонный язык ML-семейства с сильной статической типизацией и выводом типов Хиндли-Милнера.

- **Парадигма:** мультипарадигменный (ФП + мощная ООП-подсистема)
- **Типизация:** статическая с выводом типов Хиндли-Милнера
- **Компиляция:** нативная (ocamlopt) и байткод (ocamlc)
- **Уровень поддержки ФП:** ✓✓✓ (отлично)

## Сильные стороны

1. **Вывод типов** — минимум аннотаций при максимуме безопасности
2. **Производительность** — близка к C/C++
3. **Паттерн-матчинг** — мощный и проверяемый компилятором
4. **Модульная система** — функторы и модули высшего порядка
5. **Зрелость** — проверено десятилетиями в промышленности

## Типичные применения

- Компиляторы и интерпретаторы (например, Reason, Flow)
- Формальная верификация (Coq написан на OCaml)
- Финансовые системы (Jane Street)
- Статический анализ кода
- Проекты с высокими требованиями к корректности

## Экосистема

- **Компилятор:** ocamlopt (нативный), ocamlc (байткод)
- **Менеджер пакетов:** opam
- **Библиотеки:**
  - Jane Street Base/Core — альтернативная стандартная библиотека
  - Lwt — асинхронное программирование
  - Async — асинхронность от Jane Street

## Примеры кода

Примеры для всех свойств см. в [[../fp_languages_review.md|полном обзоре]].

### Быстрый пример

```ocaml
(* Функции первого класса *)
let create_multiplier factor = fun x -> x * factor
let triple = create_multiplier 3

(* АТД и паттерн-матчинг *)
type result =
  | Ok of int
  | Error of string

let divide a b =
  if b = 0 then Error "Division by zero"
  else Ok (a / b)

match divide 10 2 with
| Ok value -> Printf.printf "Result: %d\n" value
| Error msg -> Printf.printf "Error: %s\n" msg
```
