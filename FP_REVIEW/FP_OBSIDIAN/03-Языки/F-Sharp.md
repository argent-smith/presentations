## Краткая характеристика

**F#** — потомок OCaml на платформе .NET, прагматичный ФП с интеграцией в корпоративную экосистему.

## Сильные стороны

1. **Интеграция с .NET** — доступ ко всей экосистеме
2. **Computation expressions** — синтаксический сахар для монад
3. **Type providers** — генерация типов из внешних источников
4. **Практичность** — баланс ФП и реальности корпоративной разработки
5. **Вывод типов** — Хиндли-Милнер с минимумом аннотаций

## Типичные применения

- Корпоративные приложения на .NET
- Data science и финансовое моделирование
- Постепенная миграция с C#
- Веб-приложения (Fable для frontend)

## Экосистема

- **Компилятор:** fsc, интеграция с MSBuild
- **IDE:** Visual Studio, Rider, VS Code
- **Библиотеки:** FSharpPlus, FsToolkit.ErrorHandling
