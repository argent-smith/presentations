## Краткая характеристика

**TypeScript** — JavaScript с мощной статической типизацией и продвинутыми возможностями системы типов.

## Сильные стороны

1. **Статическая типизация** — безопасность без runtime overhead
2. **Type inference** — умный вывод типов
3. **Advanced types** — union, intersection, mapped, conditional types
4. **Совместимость** — любой JS-код валиден
5. **fp-ts** — полноценное ФП с типовой безопасностью

## Типичные применения

- Масштабируемые веб-приложения
- Корпоративные проекты с большими командами
- Проекты где важна типобезопасность
- Постепенная миграция с JavaScript

## Экосистема

- **Компилятор:** tsc
- **Библиотеки:** fp-ts (category theory), NeverThrow (Result)
- **Интеграция:** работает везде где JavaScript
