## Краткая характеристика

**Python** — практичный язык с акцентом на читаемость и простоту, функциональные инструменты в stdlib.

## Сильные стороны

1. **Читаемость** — код как псевдокод
2. **Функциональные инструменты** — map, filter, reduce, itertools
3. **List comprehensions** — декларативная обработка списков
4. **Generators** — ленивые вычисления
5. **Экосистема** — огромная, особенно для data science

## Типичные применения

- Data Science и Machine Learning
- Научные вычисления (NumPy, SciPy)
- Автоматизация и скрипты
- Быстрое прототипирование

## Экосистема

- **Менеджер пакетов:** pip, Poetry, conda
- **Библиотеки:** returns (monads), toolz, funcy
- **Type hints:** mypy для статической проверки
