# Obsidian Vault: Функциональное программирование

Этот каталог представляет собой **Obsidian vault** — структурированную базу знаний для навигации по материалам обзора функционального программирования.

## Как открыть в Obsidian

1. **Установите Obsidian** (если еще не установлен)
   - Скачайте с https://obsidian.md
   - Obsidian бесплатен для личного использования

2. **Откройте vault**
   - Запустите Obsidian
   - Нажмите "Open folder as vault"
   - Выберите папку `FP_OBSIDIAN`

3. **Начните с главной страницы**
   - Откроется [[README.md|README]] — главная навигационная страница (MOC)
   - Следуйте инструкциям в [[_Как использовать.md]]

## Что это дает

- **Граф связей** — визуализация отношений между концепциями ФП
- **Быстрая навигация** — между свойствами, языками и примерами
- **Поиск по тегам** — фильтрация материалов по категориям
- **Backlinks** — автоматические обратные ссылки
- **Preview** — предпросмотр заметок при hover

## Структура

```
FP_OBSIDIAN/
├── README.md                    # MOC (Map of Content)
├── _Как использовать.md         # Руководство пользователя
├── 00-Введение/                 # Базовые концепции ФП
├── 01-Фундаментальные-свойства/ # 5 основных свойств
├── 02-Вспомогательные-свойства/ # 7 дополнительных свойств
├── 03-Языки/                    # Описания 11 языков
├── 04-Сравнения/                # Сравнительные таблицы
└── 05-Ресурсы/                  # Материалы для изучения
```

## Связь с исходным материалом

Vault создан как навигационная структура поверх [[../fp_languages_review.md]]:
- **Заметки в vault** — концепции, связи, навигация
- **Полный обзор** — детальные примеры кода на всех языках

## Теги для навигации

- `#фундаментальное` — базовые свойства ФП
- `#вспомогательное` — дополнительные свойства ФП
- `#язык` — описания языков программирования
- `#примеры` — примеры кода
- `#сравнение` — сравнительные таблицы
- `#ресурсы` — материалы для изучения

## Без Obsidian

Vault остается читаемым и без Obsidian:
- Все файлы — обычный Markdown
- Ссылки работают в любом Markdown-редакторе
- Можно читать прямо в GitHub/GitLab

Но Obsidian добавляет:
- Граф связей
- Удобную навигацию
- Поиск и фильтры
- Плагины для расширения
