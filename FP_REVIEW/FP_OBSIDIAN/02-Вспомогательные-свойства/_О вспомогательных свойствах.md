# О вспомогательных свойствах

← [[README|Главная]] | [[01-Фундаментальные-свойства/_О фундаментальных свойствах|Фундаментальные свойства]]

## Определение

Вспомогательные свойства — это механизмы и инструменты, которые **облегчают реализацию** [[01-Фундаментальные-свойства/_О фундаментальных свойствах|пяти фундаментальных свойств]] функционального программирования.

## Семь вспомогательных свойств

1. **[[02-Вспомогательные-свойства/Композиция функций|Композиция функций]]**
   - Построение сложной функциональности из простых функций
   - Операторы `|>`, `>>`, `.` для цепочек преобразований
   - Каррирование и частичное применение

2. **[[02-Вспомогательные-свойства/Рекурсия и TCO|Рекурсия вместо итерации]]**
   - Повторяющиеся вычисления без изменяемого состояния
   - Tail Call Optimization (TCO) для эффективности
   - Рекурсия как идиоматичный подход

3. **[[02-Вспомогательные-свойства/АТД|Алгебраические типы данных (АТД)]]**
   - Типы-суммы (variants/enums) — перечисление альтернатив
   - Типы-произведения (records/tuples) — комбинации значений
   - Конструирование типов, исключающих недопустимые состояния

4. **[[02-Вспомогательные-свойства/Сопоставление с образцом|Сопоставление с образцом]]**
   - Элегантная деструктуризация иммутабельных структур
   - Естественно работает с АТД
   - Проверка полноты покрытия компилятором

5. **[[02-Вспомогательные-свойства/Статическая типизация|Статическая типизация с выводом типов]]**
   - Безопасность на этапе компиляции
   - Вывод типов Хиндли-Милнера — минимум аннотаций
   - "Наиболее общий тип" автоматически

6. **[[02-Вспомогательные-свойства/Ленивые вычисления|Ленивые вычисления]]**
   - Откладывание вычислений до момента использования
   - Бесконечные структуры данных
   - Оптимизация производительности

7. **[[02-Вспомогательные-свойства/Изоляция эффектов|Изоляция эффектов]]**
   - Явное отделение чистой логики от эффектных операций
   - Result/Either для обработки ошибок
   - IO монады для изоляции ввода-вывода

## Связь с фундаментальными свойствами

Вспомогательные свойства **не обязательны** для функционального программирования, но значительно облегчают его применение:

- **Композиция** естественно возникает из [[01-Фундаментальные-свойства/Функции первого класса|функций первого класса]]
- **Рекурсия** заменяет циклы при [[01-Фундаментальные-свойства/Иммутабельность|иммутабельности]]
- **АТД и паттерн-матчинг** упрощают работу с иммутабельными данными
- **Статическая типизация** помогает гарантировать [[01-Фундаментальные-свойства/Чистые функции|чистоту]]
- **Ленивость** сохраняет [[01-Фундаментальные-свойства/Выражения|композируемость выражений]]
- **Изоляция эффектов** делает чистоту явной и контролируемой
