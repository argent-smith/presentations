# Капля ФП в мире лошадей и хомячков

Доклад о практическом применении элементов функционального программирования для решения реальных проблем разработки.

## Содержание доклада

### Основные темы

1. **Проблемы программ и программистов** - аппаратура, качество кода, когнитивная сложность
2. **Капля ФП расширяет сознание** - как ФП помогает справляться со сложностью:
   - Декларативность против когнитивной сложности
   - Лямбда-исчисление для упрощения алгоритмов
   - Иммутабельность для управления данными
   - Функциональная декомпозиция против сложности задач
3. **А хомячка разрывает на части** - барьеры внедрения:
   - Налог на мозг: алгебра, семантическая плотность, дообучение
   - Сопротивление сообщества и ужас бизнеса
4. **ФП повсюду, но не там, где хочется** - ФП как традиционный стиль программирования
5. **De beneficia mentis** - польза мышления:
   - ФП как фабрика хорошего кода
   - Ум программиста как долговременный актив

### Метафора доклада

Лошадь - опытный разработчик с широким кругозором, для которого элементы ФП открывают новые возможности.
Хомячок - разработчик с узким фокусом, для которого переход к ФП может быть болезненным.

- Технические лиды, оценивающие целесообразность внедрения ФП-подходов

## Уровень

Начальный - доклад объясняет, как элементы ФП помогают решать практические задачи, без глубокого погружения в теорию.

## Ключевая ценность

Участники поймут, как использовать элементы функционального программирования для борьбы со сложностью в реальных проектах, а также осознают барьеры внедрения и способы их преодоления. Доклад показывает, что ФП - это не академическая экзотика, а традиционный стиль программирования, доступный в обычных языках.
