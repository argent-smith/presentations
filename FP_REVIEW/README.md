## Фундаментальные свойства ФП

1. **Функции первого класса** — функции как полноправные объекты языка
2. **Чистые функции** — предсказуемость без побочных эффектов
3. **Иммутабельность** — неизменяемые данные по умолчанию
4. **Декларативный стиль** — описание "что", а не "как"
5. **Выражения** — все конструкции возвращают значения

## Вспомогательные свойства

1. Композиция функций
2. Рекурсия и TCO
3. Алгебраические типы данных (АТД)
4. Сопоставление с образцом
5. Статическая типизация с выводом типов Хиндли-Милнера
6. Ленивые вычисления
7. Изоляция эффектов

## Языки

### Преимущественно функциональные
- **OCaml** — эталон ML-семейства, строгая типизация
- **F#** — OCaml для .NET, практичный ФП
- **Clojure** — современный Lisp на JVM
- **Scala** — баланс ФП и ООП

### Системные с поддержкой ФП
- **Rust** — безопасность памяти, сильные ФП-возможности
- **Go** — простота, минимальная поддержка ФП
- **C++** — производительность, современные ФП-возможности

### Веб-ориентированные
- **JavaScript** — функции первого класса, гибкость
- **TypeScript** — типобезопасность, продвинутая типизация

### Интерпретируемые
- **Ruby** — выразительность, ФП через библиотеки
- **Python** — практичность, функциональные инструменты
- **Java** — корпоративная среда, Stream API
